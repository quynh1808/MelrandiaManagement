# Hướng dẫn source code MelrandiaManagement

## Mục đích

File này là bản đồ source cho người mới tiếp nhận. Nó giải thích mục đích, lý do và quan hệ của các folder/file quan trọng; tài liệu không thay thế việc đọc code hoặc migration review.

## Luồng đọc khuyến nghị

1. `README.md` để biết tính năng và lệnh chạy.
2. `Program.cs` để thấy composition root, middleware và endpoint.
3. `Models/PortalModels.cs`, `Models/ArticleModels.cs` và `Data/ManagementDbContext.cs` để hiểu dữ liệu.
4. `PortalDatabaseInitializer` và `PortalAdministrationService` để hiểu use case.
5. `Routes.razor`, layout và pages để hiểu UI.
6. `compose.yaml`, workflow và Docs 05 để hiểu vận hành.

## `Configuration/`

- `PortalOptions.cs`: typed options cho PostgreSQL, bootstrap admin, AMS seed/health, cache public registry và giới hạn media bài viết. Typed option tránh đọc string key rải rác.
- `PortalOptionsValidation.cs`: fail-fast khi password/host/port/URL/chu kỳ/cache TTL hoặc giới hạn upload không hợp lệ; lỗi cấu hình dừng startup rõ ràng thay vì gây lỗi muộn.

## `Models/`

- `PortalModels.cs`: định nghĩa Identity user, project registry, project access, audit và DTO cho Management. Model MM chỉ mô tả portal, không chứa model ao/cảm biến.
- `PublicProjectPreview.cs`: projection an toàn cho trang công khai; không được thêm health error, access hoặc secret.
- `PublicArticleCategory.cs`: projection chuyên mục an toàn cho header/trang public, kèm số bài đã công bố.
- `ArticleModels.cs`: entity category/article/media, trạng thái xuất bản, request/DTO admin và DTO public. Tách DTO ngăn public UI vô tình nhận storage path, draft hoặc ID nội bộ.

## `Data/` và `Migrations/`

- `ManagementDbContext.cs`: EF unit of work và schema mapping. Unique index bảo vệ key/slug ở database, composite key bảo vệ một quyền trên một user/project.
- `ManagementDbContextFactory.cs`: design-time factory để `dotnet ef` đọc appsettings, User Secrets và biến môi trường giống web host. Khi command chỉ kiểm tra model trong CI và không có secret, factory dùng placeholder; `database update` trên máy thật dùng password đã cấu hình.
- `PortalDatabaseInitializer.cs`: áp migration, tạo role, seed AMS/Agriculture, ba article category và đảm bảo admin/access lần đầu; không reset password cũ.
- `Migrations/*InitialManagementSchema*`, `*AddArticlePublishing*`, `*AddArticleConcurrencyControl*`: lịch sử schema/model có thể review, chạy trên Windows/Ubuntu và kiểm tra drift trong CI; concurrency migration không có DDL vì token là hành vi EF.

## `Services/`

- `PortalAdministrationService.cs`: application service cho dashboard, registry, account, grant/revoke, Administrator recovery và audit. Đây là lớp duy nhất UI quản trị gọi cho nghiệp vụ persistence.
- `PublicProjectCatalog.cs`: singleton read-only adapter từ registry sang DTO công khai. Nó dùng IMemoryCache, cache-miss gate và explicit invalidation để header/page dùng chung snapshot mà public UI vẫn không phụ thuộc entity EF.
- `PublicArticleCatalog.cs`: singleton cached read model của chuyên mục/bài public; tự lọc draft/archive và render Markdown an toàn.
- `ArticleAdministrationService.cs`: write use case cho tạo/chỉnh sửa, status/schedule validation, optimistic version, transaction, audit và cache invalidation.
- `ArticleMediaStorage.cs`: kiểm tra magic bytes/dung lượng, tạo đường dẫn không đoán trước và lưu/xóa file trong persistent root.
- `ArticleMarkdownRenderer.cs`: Markdig pipeline có raw HTML bị tắt và từ chối URL scheme nguy hiểm.

## `Runtime/` và `Infrastructure/`

- `PortalBootstrapHostedService.cs`: chạy initializer trước khi app phục vụ ổn định; startup fail nếu schema/secret nền tảng sai.
- `ProjectHealthMonitor.cs`: BackgroundService polling endpoint project; lỗi project con chỉ cập nhật state.
- `PostgreSqlHealthCheck.cs`: dependency check cho `/health/ready`; `/health/live` không chạy check này.

## `Components/`

- `App.razor`: HTML shell, CSS/JS, theme init, Interactive Server render mode và reconnect overlay.
- `Layout/ReconnectModal.razor`: trạng thái reconnect/retry/rejected/paused khi Blazor circuit mất kết nối; ID/class tuân theo contract framework.
- `Routes.razor`: Router + CascadingAuthenticationState + AuthorizeRouteView.
- `Layout/PublicLayout.razor`: header/footer cho website công khai.
- `Layout/AuthLayout.razor`: layout tối giản cho login; ngăn header/footer public xuất hiện ở ngữ cảnh xác thực.
- `Layout/ManagementLayout.razor`: sidebar dùng chung cho toàn bộ module, topbar search/theme và account dropdown có POST logout.
- `Pages/Login.razor`: form login SSR có antiforgery và safe return URL.
- `Pages/Management.razor`: dashboard real data, status filter, activity/alert/system overview.
- `Pages/ManagementProjects.razor`: create/edit Project Registry.
- `Pages/ManagementSystems.razor`: read model network/connection từ URL, health và latency.
- `Pages/ManagementTasks.razor`: checklist commissioning tự sinh, không giả lập task persistence.
- `Pages/ManagementAlerts.razor`: cảnh báo suy ra từ health/configuration hiện tại.
- `Pages/ManagementReports.razor`: tổng hợp project coverage, latency và audit.
- `Pages/ManagementIntegrations.razor`: catalog dependency PostgreSQL/HTTP; không render secret.
- `Pages/ManagementArticles.razor`: tạo bài multipart, lọc trạng thái và registry bài.
- `Shared/EditArticleForm.razor`: chỉnh sửa bài có version, upload ảnh bổ sung và preview.
- `Pages/ManagementArticlePreview.razor`: xem draft có authorization.
- `Pages/Articles.razor`, `ArticleCategory.razor`, `ArticleDetail.razor`: public CMS list/category/detail từ DTO an toàn.
- `Pages/ManagementUsers.razor`: tạo Central Identity.
- `Pages/ManagementAccess.razor`: cấp/thu hồi project access.
- `Shared/RedirectToLogin.razor`: đưa request không xác thực về login và giữ local return URL.
- Các public page/shared component: dựng nội dung thương hiệu và projection công khai, không truy cập AMS database.

## `wwwroot/`

- `app.css`: design tokens, light/dark, public layout, auth, Management/article responsive và reconnect overlay. Times New Roman được định nghĩa tập trung.
- `js/theme-init.js`: chạy sớm trước paint để tránh chớp sai theme.
- `js/site.js`: progressive enhancement cho dropdown, theme, mobile menu, password visibility, search, status filter và scroll reveal. Search/status cùng gọi một hàm để không ghi đè điều kiện của nhau.
- `images/avatar.png`: ảnh nhận diện do chủ dự án cung cấp.
- `images/languages/*.svg`: cờ cho language picker; EN mới là placeholder UI.
- `App_Data/media` (runtime, Git ignored): byte ảnh upload trên Windows; production thay bằng named volume.

## `postgres-init/`, `scripts/`, `Tests/`, `Docs/`

- `postgres-init/create-management-database.sql`: tạo role/database native PostgreSQL mà không lưu password.
- `scripts/deploy-ubuntu.sh`: validate `.env`, Docker access, pull immutable image và compose up; không tự giải quyết Git conflict.
- `Tests/`: unit/model contract test, gồm public article visibility, Markdown validation và upload file vào thư mục tạm; không ghi production database.
- `Docs/`: quyết định kiến trúc, setup, validation và handover theo thứ tự đánh số.

## Ý nghĩa phần mở rộng file

- `.cs`: C# source, model/service/host logic được compiler kiểm tra kiểu.
- `.razor`: Razor component kết hợp HTML markup và C# render logic.
- `.csproj`: MSBuild project, framework/package/container metadata.
- `.sln`: solution gom nhiều project.
- `.json`: configuration/tool/lock data có cấu trúc; JSON không hỗ trợ comment chuẩn.
- `.yaml`/`.yml`: cấu hình phân cấp cho Compose và GitHub Actions; thụt lề quyết định cấu trúc.
- `.css`: style, responsive, theme và animation.
- `.js`: JavaScript chạy trong browser để tăng cường tương tác.
- `.sql`: câu lệnh PostgreSQL quản trị/schema thủ công.
- `.sh`: Bash script cho Ubuntu; Git phải giữ LF và executable bit.
- `.md`: Markdown giải thích kiến trúc/quy trình; không được ứng dụng thực thi.
- `.lock.json`: dependency lock do .NET restore quản lý; phải commit và không sửa tay.

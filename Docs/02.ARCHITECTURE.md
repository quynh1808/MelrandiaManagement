# Kiến trúc và ranh giới MelrandiaManagement

## Vai trò của ứng dụng

MelrandiaManagement là một website độc lập, không phải thư mục cha chứa source của mọi dự án. AMS, các dự án giám sát cây trồng hoặc chăn nuôi tương lai tiếp tục có repository, container, database và chu kỳ phát hành riêng.

## Kiến trúc giai đoạn trang chủ

```text
Browser
  └─ ASP.NET Core / Blazor Static SSR
       ├─ PublicLayout
       ├─ Public pages
       ├─ PublicProjectCatalog
       ├─ PublicArticleCatalog
       └─ Static CSS/JavaScript
```

Static Server Rendering tạo HTML trên server cho từng request. Đây là lựa chọn phù hợp cho website công khai vì trang vẫn tải được mà không cần duy trì một Blazor Server circuit. JavaScript chỉ đảm nhận theme, menu và animation.

## Ranh giới với AquacultureMonitoringSystem

Phiên bản hiện tại không có project reference đến AMS, không đọc MongoDB AMS và không gửi lệnh MQTT/Modbus. Tên AMS trong catalog chỉ là metadata công khai. Ranh giới này ngăn thay đổi hoặc lỗi của Portal ảnh hưởng đến điều khiển thiết bị.

Trong giai đoạn tích hợp, AMS sẽ cung cấp health/summary API. MelrandiaManagement gọi API bằng kết nối server-to-server; trình duyệt không được nhận service secret.

## PublicProjectCatalog

Catalog dùng singleton in-memory để giữ phạm vi trang chủ nhỏ và không thêm database trước khi nghiệp vụ quản trị được xác định. UI chỉ phụ thuộc API `GetPublishedProjects` và `FindBySlug`. Sau này một repository MongoDB có thể thay thế catalog nhưng vẫn trả cùng model công khai.

`PublicArticleCatalog` áp dụng cùng nguyên tắc cho ba chuyên mục Kinh tế, Công nghệ và Giới thiệu sách. Việc định nghĩa slug ở catalog giúp menu header, trang danh mục và route chi tiết dùng cùng một URL ổn định trước khi CMS tồn tại.

## PublishContainer

`MelrandiaManagement.csproj` khai báo container repository, port `8080` và user không phải root. `.NET SDK PublishContainer` tạo OCI image mà không cần Dockerfile. Port host và image GHCR sẽ được định nghĩa trong repository deployment sau khi giao diện được nghiệm thu.

## Thuật ngữ

- **Portal/Management site**: Website trung tâm hiển thị và quản lý catalog dự án.
- **Static SSR**: Server tạo HTML hoàn chỉnh cho request, không yêu cầu circuit lâu dài.
- **Project Registry**: Danh mục bền vững của các project, URL, quyền và trạng thái.
- **Slug**: Chuỗi ngắn, không dấu dùng trong URL để xác định đúng dự án hoặc chuyên mục, ví dụ `cong-nghe`.
- **CMS**: Content Management System, hệ thống cho phép quản trị viên tạo, chỉnh sửa và xuất bản bài viết mà không sửa source code.
- **Mega dropdown**: Menu thả xuống chứa nhiều link kèm mô tả; ở dự án này nó vẫn được giới hạn kích thước để header gọn.
- **Progressive enhancement**: HTML vẫn có ý nghĩa trước khi JavaScript bổ sung tương tác.
- **Health endpoint**: URL máy có thể gọi để xác định process sẵn sàng phục vụ.
- **OCI image**: Định dạng image tiêu chuẩn chạy được bằng Docker/container runtime.
- **Immutable tag**: Tag release không thay đổi nội dung, thường là `sha-*`.
